# Plan.md

## Цель
Разработать серверное приложение-сейф для надежного хранения учетных записей:
- сайт
- логин
- пароль
- примечание

Приложение должно:
- безопасно хранить секреты
- работать на Java 21 + Spring Boot
- использовать PostgreSQL и Flyway
- разворачиваться в Docker
- поддерживать аудит, резервное копирование и эксплуатацию

## Формат продукта
Основной формат первой версии:
- **Backend REST API**
- OpenAPI документация
- административные операции
- механизмы надежности и восстановления

Веб-интерфейс считается опциональным и вынесен отдельной задачей.

## Рамки проекта
### Входит в scope
- регистрация/создание пользователей
- аутентификация
- авторизация
- хранение записей сейфа
- шифрование секретов
- аудит
- ротация мастер-ключа
- Docker-развертывание
- backup/restore
- тесты

### Не входит в scope первой версии
- шаринг секретов между пользователями
- полноценная мультифакторная аутентификация
- распределенная высокодоступная архитектура
- мобильные приложения
- клиентские десктопные приложения
- продвинутый полнотекстовый поиск по зашифрованным данным
